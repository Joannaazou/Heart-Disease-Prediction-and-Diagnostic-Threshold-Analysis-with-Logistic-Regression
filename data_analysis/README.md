# R Data Analysis Workflow

## Folder Structure

```text
data_analysis/
├── README.md
├── heart-disease-logistic.R
├── heart_disease_cleveland.csv
├── session_info.txt
├── plots/
└── output/
```

## Required Files

| File | Purpose |
|---|---|
| `heart-disease-logistic.R` | Main R script containing data cleaning, exploratory analysis, modeling, evaluation, and threshold analysis. |
| `heart_disease_cleveland.csv` | Input dataset used by the R script. (source https://archive.ics.uci.edu/dataset/45/heart+disease) |
| `session_info.txt` | R version, operating system, and package-version record generated after analysis. |
| `plots/` | Folder for figures generated by the analysis. |
| `output/` | Folder for tables or other generated analysis outputs. |

## Required R Packages

Install the following packages in RStudio before running the script:

```r
install.packages(c(
  "caret",
  "car",
  "corrplot",
  "pheatmap",
  "DescTools",
  "pROC"
))
```

## Run the Analysis

1. Open RStudio.
2. Set the working directory to the `data_analysis` folder.
3. Confirm that `heart-disease-logistic.R` and `heart_disease_cleveland.csv` are in the same folder.
4. Run:

```r
source("heart-disease-logistic.R")
```

Alternatively, open `heart-disease-logistic.R` in RStudio and run it from top to bottom.

## Create Folders

If the `plots/` and `output/` folders do not already exist, create them before running code that saves figures or tables:

```r
dir.create("plots", showWarnings = FALSE)
dir.create("output", showWarnings = FALSE)
```

## Record Session Information

After running the analysis, create or update `session_info.txt` with:

```r
sink("session_info.txt")
sessionInfo()
sink()
```

This records the R version, operating system, and loaded package versions used for the analysis.
